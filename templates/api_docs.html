GET /health System health & database status check ▼

Returns live status of the application and database. No authentication required. Ideal for uptime monitors and deployment health checks.

GET /api/complaints List all complaints (paginated) Admin ▼

Returns a paginated, filterable list of all complaints. Requires admin login.

Query Parameters
ParameterTypeDefaultDescription
pageinteger1Page number optional
per_pageinteger10Results per page optional
statusstring—Filter by status: Pending, In Progress, Resolved, Rejected optional
prioritystring—Filter by priority: Low, Medium, High optional
searchstring—Search by tracking ID or title optional
Response (200 OK)
{
  "complaints": [
    {
      "id": 1,
      "tracking_id": "CMP-A1B2C3D4",

GET /api/complaints/<id> Get single complaint detail Auth required ▼

Returns full detail of a single complaint. Users can only view their own complaints; admins can view any.

Path Parameters
ParameterTypeDescription
idintegerComplaint database ID required
